# ألعاب أندرويد بالإعلانات

| اللعبة | المجلد | الفكرة |
|---|---|---|
| تحدي الأعلام والعواصم | [flags_challenge](flags_challenge) | ٤٠ مرحلة، تحدي البقاء، تحدي يومي، تدريب حر، ١٨٨ دولة |
| فرز الألوان | [color_sort](color_sort) | مراحل لا نهائية مضمونة الحل، تراجع وأنبوب إضافي |
| القفزة | [sky_jump](sky_jump) | قفز لا نهائي، منصات متحركة ومكسورة ونوابض، عملات |

كل لعبة مبنية بـ Flutter مع إعلانات AdMob (بانر، بيني كل ٣ جولات، ومكافأة مقابل العملات والمساعدات).

## التنزيل
بعد كل تحديث على `main` يبني GitHub كل لعبة، يجربها على جوال أندرويد افتراضي، ثم ينشر ملف APK في صفحة **Releases**.

## قبل النشر على Google Play
استبدل معرّفات AdMob التجريبية في كل لعبة:
- `android/app/src/main/AndroidManifest.xml` (معرّف التطبيق)
- `lib/ads/ad_manager.dart` (معرّفات الإعلانات)
